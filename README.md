# Claimr

Claimr is the creator earnings optimization website built to recover hidden payments, bonus rewards, and monetization opportunities across TikTok, YouTube, Facebook, and Instagram.

## Development

Install dependencies:

```bash
npm install
```

Run development server on port 5000:

```bash
npm run dev -- --port 5000
```

Build for production:

```bash
npm run build
```

## Deploy

This project is configured for Netlify using `netlify.toml`. Deploy the app by connecting the repository to Netlify and running the build command.
